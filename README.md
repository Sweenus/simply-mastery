# Simply Swords: Mastery

Simply Swords: Mastery adds a weapon-specific skill tree to each supported Simply Swords unique weapon. Earn mastery XP in combat, spend mastery points at the Runic Forge, and reshape how that weapon's abilities behave.

Progress belongs to the item by default, so a weapon you hand to a friend arrives with its mastery intact.

## Requirements

Minecraft **1.21.1**, Java **21**, on Fabric or NeoForge.

| Dependency | Minimum version |
|---|---|
| Simply Swords | 1.71.0-1.21.1 |
| Simply Tooltips | 0.1.5 |
| Architectury API | 13.0.11 |
| Fzzy Config | 0.7.6 |
| Fabric Loader (Fabric only) | 0.18.4, plus Fabric API |
| NeoForge (NeoForge only) | 21.1.219 |

Install Simply Swords: Mastery on both the client and the server. See [Installation](documentation/installation.md) for the details.
