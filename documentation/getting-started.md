# Getting started

[Documentation index](README.md)

## 1. Earn mastery XP

Fight eligible enemies while holding a supported Simply Swords unique weapon. Melee hits, weapon abilities, projectiles, summons and attributed damage over time all count by default.

Mastery XP is separate from vanilla experience levels. It is stored per weapon, not on your XP bar.

Passive mobs, other players, your own pets, and teammates award nothing by default.

## 2. Open the Mastery screen

Place the weapon in the **Runic Forge**, then press the **Mastery** button.

The button is disabled if mastery is turned off on the server, if the weapon has no mastery profile, or if you are holding an item on the cursor.

## 3. Spend points

Select a node to see its effect, its prerequisites and its point cost. Unlock it when you have the points and its prerequisites are met.

Each tree has three branches and 27 nodes. Ordinary nodes cost 1 point, capstones cost 2. Each branch ends in a pair of capstones and you can only ever take one of the pair.

See [The Mastery screen](mastery-screen.md) for the controls and the node glyphs.

## Default numbers

| | Default |
|---|---|
| Starting points | 0 |
| Maximum earned points | 18 |
| XP for the first point | 100 |
| XP for the second point | 135 |

Costs climb steeply after the fourth point. The server can change all of this, so your server's numbers may differ. See [Progression](progression.md) for the formula and the full cost table.

## Changing your mind

**Respec** returns every point you have spent in the current tree. It does not remove earned XP, earned points or first-kill history.

It costs **3 Runic Tablets** from your inventory by default, and creative players pay nothing. The server can change the item, change the quantity, or disable respec entirely.

## Who keeps the mastery?

By default, progression lives on the **weapon**. Give the weapon away and its mastery goes with it.

The server can switch to **player** ownership instead, where mastery is yours and stays with you. See [Progression](progression.md#ownership).
